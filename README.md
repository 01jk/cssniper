# CSFloat Sniper Bot

Продвинутый бот для автоматического мониторинга и снайпинга скинов на торговой площадке **CSFloat**. Проект предназначен для отслеживания новых листингов в реальном времени, фильтрации их по сложным критериям (Float, паттерны, стикеры, Blue Gem) и моментального оповещения пользователя или автоматической покупки (в зависимости от конфигурации).

---

## 🏗 Архитектура проекта

Проект разделен на два основных компонента: высокопроизводительный бэкенд на Rust и современный веб-интерфейс на React.

### 1. Бэкенд (`rust-core/`)
Ядро системы было переписано с Python на **Rust** для обеспечения максимальной скорости работы, многопоточности и стабильности при высоких нагрузках.
* **Технологии**: Rust, Tokio (асинхронный рантайм), Axum (веб-сервер/API), SQLx (работа с БД SQLite), Reqwest (HTTP-клиент).
* **Функционал**:
  * Непрерывный поллинг/мониторинг новых листингов CSFloat.
  * Продвинутая система фильтрации: проверка Float, цены, наличия и износа стикеров, брелоков (charms), расчет процента синего (Blue Gem) для ножей (Playside/Backside).
  * Рассылка уведомлений в Telegram.
  * Предоставление REST API для фронтенда.

### 2. Фронтенд (`sn1perb0t111-main/`)
Удобная панель управления (Dashboard) для настройки бота и просмотра результатов в реальном времени.
* **Технологии**: React 18, Vite, TypeScript, TailwindCSS, shadcn/ui.
* **Функционал**:
  * **Live Monitor**: лента новых предметов в реальном времени с отображением стикеров, износа, бейджей и других важных параметров.
  * **Watchlist**: список отслеживаемых предметов с проверкой изменения цен.
  * Управление целями (Targets) и фильтрами.
  * Панель уведомлений и статусов работы ядра.

### 3. База данных
* Используется **SQLite** (`cssniper.db` / `sniper.db`), что обеспечивает портативность и простоту деплоя без необходимости разворачивать отдельные СУБД.

## ✨ Основные возможности

* **Молниеносный парсинг**: благодаря Rust-бэкенду минимизирована задержка между появлением предмета на CSFloat и его анализом.
* **Сложные фильтры**:
  * Ограничения по цене и Float.
  * Поиск конкретных паттернов (включая детальный анализ Blue Gem).
  * Поиск предметов со специфическими наклейками (Stickers) и расчет Sticker Price (SP%).
  * Поддержка новых атрибутов CS2, таких как брелоки (charms).
* **Telegram Интеграция**: моментальные уведомления о найденных предметах напрямую в один или несколько Telegram-чатов.
* **Гибкая настройка UI**: кастомизация Live Monitor (размеры карточек, формат отображения иконок и цен).

## 🚀 Установка и запуск (Local Development)

### Требования
* [Rust & Cargo](https://www.rust-lang.org/tools/install) (версия 1.86.0 из `rust-core/rust-toolchain.toml`)
* [Node.js](https://nodejs.org/) (версия 18+)
* Python 3 с SQLAlchemy для создания исходных таблиц SQLite

### 1. Настройка Бэкенда (Rust)

Из корня свежей копии создайте рабочий конфиг из [settings.example.yaml](config/settings.example.yaml). В PowerShell:

```powershell
Copy-Item config/settings.example.yaml config/settings.yaml
```

В Linux и macOS используйте `cp config/settings.example.yaml config/settings.yaml`. Задайте собственные `web_auth.username` и `web_auth.password` для входа в панель. Ключ CSFloat задаётся в `scanner.api_key`, настройки уведомлений — в разделе `bot`. Для отдельного второго профиля создайте из того же шаблона `config/settings.config2.yaml`.

Создайте пустую базу из [моделей проекта](database/models.py). Выполните из корня:

```bash
python -m pip install "SQLAlchemy>=2.0"
python -c "from database.database import init_db; init_db()"
cd rust-core
cargo run
```

По умолчанию база находится в корне проекта (`cssniper.db`), а API слушает порт `8000`.

### 2. Настройка Фронтенда
В новом окне терминала:
```bash
cd sn1perb0t111-main
npm install
# или
# yarn install / pnpm install
```

Запуск development сервера:
```bash
npm run dev
```
После этого откройте ссылку из терминала Vite. В конфигурации проекта задан `http://localhost:8080`, запросы к `/api` перенаправляются на `127.0.0.1:8000`.

## ☁️ Деплой (Railway)

Проект настроен для деплоя на платформе [Railway](https://railway.app/).
1. Файл `railway.json` в корне проекта указывает платформе, как собирать и запускать Rust-бэкенд.
2. На постоянном томе подготовьте рабочий YAML из шаблона и укажите его абсолютный путь в `CONFIG_PATH`, например `/data/settings.yaml`. Для чистой установки создайте `cssniper.db` приведённой выше командой `init_db()` с тем же `CONFIG_PATH`. Rust ищет базу рядом с конфигом. Токены и параметры входа задаются в рабочем YAML.
3. Логи бэкенда пишутся в консоль и файлы (например, `rust_core.log`), что позволяет удобно мониторить статус в дашборде Railway.

## 🔧 Устранение неполадок (Troubleshooting)

* **403 Forbidden (CSFloat API)**: Убедитесь, что ваш API-ключ добавлен в конфигурацию и имеет правильные права доступа.
* **429 Too Many Requests**: Увеличьте интервал между запросами в разделе `scanner` рабочего конфига.
* **Ошибка компиляции Rust**: Убедитесь, что у вас установлена последняя стабильная версия Rust (`rustup update`). В логах могут быть предупреждения (например, неиспользуемые поля `float_rank_value` — их можно игнорировать или закомментировать).
